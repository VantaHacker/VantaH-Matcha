# VantaH-Matcha

Matcha scripts. Made by VantaH.

--------------------------------------------------------------------------------
## Dandy's World
ESP and automation for Dandy's World.
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/VantaHacker/VantaH-Matcha/refs/heads/main/DW.lua"))()
```
Includes a lot of useful settings, such as:

1. **Visuals** (ESP for twisteds, items, machines, research capsules and tapes). Live machine fill percent and machine type, including duo machines. Dot, tracer, distance, name, room and twisted/item rarity, all toggleable.
2. **Automation** (auto skill check for every machine type). It tracks the marker's real speed and aims for the centre of the window with a randomised lead, so it stays accurate through frame jitter. Auto Barnaby is the most advanced one and includes safe coin collection. Auto bar, auto circle and auto treadmill are included as well.
3. **Alerts** (advanced settings where you can monitor dangerous twisteds and useful items). Currently 15 twisteds and 10 items you can individually watch. Notifies once per spawn and highlights items in pink. Extra tracers are included for easier monitoring.
4. **Misc**: Auto Barnaby fully works at the lobby arcade. Setting your Roblox graphics to 1/10 manually is recommended for scores above 1000.

--------------------------------------------------------------------------------
All settings save automatically.
